研究背景与核心问题

03
📈 行业背景与定义

社交网络的兴起：以微信、微博、Facebook等服务为代表的社交圈中，蕴含着数以亿计的拓扑与连接关系。

什么是链路预测：利用已知的网络结构，预测尚未连接的两个节点在未来产生社交关联的可能性（例如可能认识的人）。

结构稀疏性：实际网络连接极度稀疏，仅有千分之几工程连接被观测，增加了预测难度。

🎯 核心待解决挑战

1. 均匀随机游走的盲目性： 原版 DeepWalk 游走在每个邻居之间的概率完全均等，忽略了不同好友之间的社交紧密性差异。

2. 结构相似度与高阶嵌入的失衡： 业界缺乏一种数学理论机制，将一阶的静态相似度指标（如 Jaccard）无缝融入高阶网络表示学习中。

3. 硬件友好与低算力瓶颈： 摆脱大型深度神经网络对庞大显存 GPU 的依赖，在普通 CPU 上几秒内输出精确结果。

研究意义与应用价值

04
📚 理论意义

融合经典拓扑与网络表示学习：桥接了以往两个相互分裂的方法论，用邻域相似性作为图表示探索的先验引导。

提出概率调控平滑模型：建立起一套包含调节因子的转移概率，让全局结构探索和局部社区开发可调、可解释。

💻 实际应用价值

社交好友精准推荐：提升社交平台“感兴趣的好友”推荐成功率，辅助社交链条的快速扩展与用户粘性。

生物医药研发：应用于蛋白质相互作用网络（PPI）中，快速锁定未被发掘的连接，缩短新药靶向筛选时长。

安全与反作弊：应用于学术网络中的合作关系异常检测，或金融作弊网络中黑色产业链的异常边关联预测。

国内外研究现状分析

05
🔍 传统启发式链路预测方法

代表模型：Jaccard 系数、Common Neighbors、Adamic-Adar、Resource Allocation 指标等。

优点：计算简便，具有强大的物理解释性与极低的特征维度占用。

缺点：通常只考虑1跳或2跳的极其局部的结构细节，对未知稀疏长程链接的泛化极其脆弱。

🕸️ 网络表示学习方法

代表模型：DeepWalk (2014), Node2Vec (2016), LINE (2015) 等图嵌入学习模型。

优点：通过随机游走与 Skip-gram 自动挖掘多阶全局结构特征，表达力卓越。

缺点：均匀游走极易将walker随机带离至边缘节点，造成表示学习训练质量下降，丢失邻域紧密结构。

研究目标与主要内容

06
🎯 研究总体目标
提出并实现一种基于 Jaccard 拓扑相似度加权转移概率的随机游走表示学习方法。通过平滑参数 β 平衡网络局部紧密度与全局搜索，提升链路预测准确率（AUC-ROC值），并在保证 CPU 轻量化运行的前提下超越现有基线。
📋 核心研究内容
  • 1. 相似度概率模型：结合无向图 Jaccard 相似度构建非均匀状态转移矩阵。
  • 2. 加权游走与嵌入：产生偏向游走，使用 gensim Skip-gram 训练 128 维节点嵌入。
  • 3. 特征分类与预测：提取边 Hadamard 乘积特征，利用逻辑回归分类器预测连边。
  • 4. 对比验证与寻优：针对平滑参数 β 等进行多组消融分析，在公开数据集测试。

关键技术与实施方案

💡 核心创新算法：Jaccard 加权转移概率公式
Jaccard(u, v) + β P'(v | u) = ------------------------------------ Σ [ Jaccard(u, w) + β ] (w ∈ N(u))
当平滑因子 β → ∞ 时，过渡为原始的均匀随机游走；当 β → 0 时，游走将完全偏爱拓扑相似度最高的邻居（局部聚集开发）。

备份幻灯片：平滑机制与边界状态分析

13
🛡️ Jaccard 相似度为 0 边界分析

边界预测：在网络稀疏区域，相邻节点对极其可能不存在共同邻居，导致其 Jaccard 相似度为 0。

公式弹性平滑：

当 $Jaccard(u, v) = 0$ 时，转移概率退化为：

P'(v | u) ∝ β

保证算法在没有邻域重叠的情况下能够根据常量 β 进行均匀探索，避免游走状态卡死。

⚙️ 平滑参数 β 的双重控制作用

β → 0 (强局部开发)：游走概率完全偏好局域拓扑紧密、相似度极高的社群节点。利于刻画微观社区结构。

β → ∞ (全局宏观探索)：相似度矩阵的影响被均匀稀释，随机游走完全退化为传统均匀游走。利于挖掘高阶全局关联。

备份幻灯片：实验规范与标签噪声防御

15
📊 1:1 负样本采样设计规范

采样流程：从图上所有不存在连接的节点对中，随机均匀抽取与正样本测试边 等量 的非相连边作为负样本。

对齐评估基准：

遵循 Liben-Nowell [5] 链路预测经典规范，使分类随机猜测基线 AUC 固定为 0.5，从而获得最客观、无偏的相对性能增量衡量。

🛡️ 潜在关系（标签噪声）的防御

什么是标签噪声：现实中“未相连的节点”可能仅是“尚未被观察到的潜在正边”，在采样中会被误标为负样本。

AUC-ROC 的天然免疫力：

AUC-ROC 是基于概率排序的客观指标。只要算法能把真实存在的正边排在预测概率的前列，微量的负样本噪声不会干扰相对排序结果，算法评估依然完全有效。
