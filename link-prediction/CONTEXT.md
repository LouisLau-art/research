## 任务与评估

| 术语 | 定义 | 别漂到 |
|---|---|---|
| 链路预测任务 | 藏 20% 边作正样本，以完整原图不存在的边作负样本；简单规则直接打分，向量方法以逐维乘积接逻辑回归打分 | 当前实现的负采样未完全做到定义中的排除 |
| 协议 A（原协议） | 随机负采样 + 原始向量 | — |
| 协议 B（修正协议） | 度数匹配负采样 + 单位归一化。仍须复核样本隔离 | 「真实排名」「可靠协议」 |
| 度数匹配负采样 | 节点按连接数切 60 等频桶，正边两端各从同桶取负节点，只近似匹配 | 「消除度数影响」 |
| 模长捷径 | 向量长度会影响逐维乘积，模型可能借用这一信息。需通过对照实验验证影响 | 把归一化的影响直接归因为节点度数 |
| 配对显著性检验 | 两个方法在同样的多次划分上逐次比较，报告变化幅度和不确定性 | 「不显著就是等价」 |

## 方法

| 术语 | 定义 |
|---|---|
| 启发式基线 | CN / Jaccard / AA（无学习判边函数） |
| 嵌入基线 | DeepWalk、Node2Vec（BFS 型 / DFS 型） |
| 本文方法 | 仅指结构相似度加权随机游走：P(v→x) ∝ α(t,x)·w(v,x)·(s(v,x)+β)^γ；s∈{Jaccard,RA,AA}。不含混合预测器 |
| β / γ | β=平滑项，避免权重全为零；γ=锐化指数，改变结构权重之间的差距 |
| 可插拔 | 相似度指标、β、γ、p/q 均为独立参数（src/advanced_walk.py），换指标只改一个参数 |
| 混合预测器 | 「换融合位置」的验证装置（week12）：E=仅嵌入 / H=仅结构（CN,Jaccard,AA,RA 归一化）/ M=concat(E,H) |
| 融合位置 | 采样级（本文方法）/ 特征级（混合预测器 M）/ 输出级（两路分数加权）。目前直接验证前两种 |
